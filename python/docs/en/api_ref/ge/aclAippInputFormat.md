# aclAippInputFormat

| AIPP Input Image Format| Description|
| --- | --- |
| ACL_YUV420SP_U8 = 1 | Supported by both static AIPP and dynamic AIPP.|
| ACL_XRGB8888_U8 = 2 | Supported by both static AIPP and dynamic AIPP. Supported by static AIPP but not supported by dynamic AIPP.|
| ACL_RGB888_U8 = 3 | Supported by both static AIPP and dynamic AIPP.|
| ACL_YUV400_U8 = 4 | Supported by both static AIPP and dynamic AIPP. Supported by static AIPP but not supported by dynamic AIPP.|
| ACL_NC1HWC0DI_FP16 = 5 | Not supported currently|
| ACL_NC1HWC0DI_S8 = 6 | Not supported currently|
| ACL_ARGB8888_U8 = 7 | Supported by both static AIPP and dynamic AIPP. Not supported currently.|
| ACL_YUYV_U8 = 8 | Supported by both static AIPP and dynamic AIPP. Not supported currently.|
| ACL_YUV422SP_U8 = 9 | Supported by both static AIPP and dynamic AIPP. Not supported currently.|
| ACL_AYUV444_U8 = 10 | Supported by both static AIPP and dynamic AIPP. Not supported currently.|
| ACL_RAW10 = 11 | Supported by both static AIPP and dynamic AIPP. Not supported currently.|
| ACL_RAW12 = 12 | Supported by both static AIPP and dynamic AIPP. Not supported currently.|
| ACL_RAW16 = 13 | Supported by both static AIPP and dynamic AIPP. Not supported currently.|
| ACL_RAW24 = 14 | Not supported currently|
| ACL_AIPP_RESERVED = 0xffff | Not supported currently|
