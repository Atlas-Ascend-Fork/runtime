# aclmdlInputAippType

| AIPP Type of the Model Input| Definition|
| --- | --- |
| ACL_DATA_WITHOUT_AIPP = 0 | This input has no AIPP information.|
| ACL_DATA_WITH_STATIC_AIPP = 1 | This input has static AIPP information.|
| ACL_DATA_WITH_DYNAMIC_AIPP = 2 | The input has an associated dynamic AIPP input.|
| ACL_DYNAMIC_AIPP_NODE = 3 | This input is a dynamic AIPP input. Used to configure dynamic AIPP attributes.|
