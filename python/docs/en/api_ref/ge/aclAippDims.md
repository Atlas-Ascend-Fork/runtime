# aclAippDims

| AIPP Dimension Information| Definition|
| --- | --- |
| srcDims | Model input and output dimension information (data of the `aclmdlIODims` type), source dims, for example, [1,3,150,150]|
| srcSize | Source data size|
| aippOutdims | Destination dimensions|
| aippOutSize | Destination data size|
