# Deprecated APIs and Return Codes

## APIs

- [acl.op.execute](function-execute-0.md)

 This API will be deprecated in later versions. Use the [acl.op.execute\_v2](function-execute_v2-1.md) API instead.

- [acl.get\_tensor\_desc\_dim](function-get_tensor_desc_dim.md)

 This API will be deprecated in later versions. Use the [acl.get\_tensor\_desc\_dim\_v2](function-get_tensor_desc_dim_v2.md) API instead.

- [acl.set\_tensor\_storage\_shape](function-set_tensor_storage_shape.md)

 This API will be deprecated in later versions. Use the [acl.set\_tensor\_shape](function-set_tensor_shape.md) API instead.

- [acl.set\_tensor\_storage\_format](function-set_tensor_storage_format.md)

 This API will be deprecated in later versions. Use the [acl.set\_tensor\_format](function-set_tensor_format.md) API instead.

## Return Codes

- [ACL\_ERROR\_NONE](aclError.md)

 This return code will be deprecated in later versions. Use the [ACL\_SUCCESS](aclError.md) return code instead.

- [ACL\_ERROR\_NOT\_STATIC\_AIPP](aclError.md)

 This return code will be deprecated in later versions. Use the [ACL\_ERROR\_GE\_AIPP\_NOT\_EXIST](aclError.md) return code instead.

- [ACL\_ERROR\_STREAM\_NOT\_SUBSCRIBE](aclError.md)

 This return code will be deprecated in later versions. Use the [ACL\_ERROR\_RT\_STREAM\_NO\_CB\_REG](aclError.md) return code instead.

- [ACL\_ERROR\_THREAD\_NOT\_SUBSCRIBE](aclError.md)

 This return code will be deprecated in later versions. Use the [ACL\_ERROR\_RT\_THREAD\_SUBSCRIBE](aclError.md) return code instead.

- [ACL\_ERROR\_WAIT\_CALLBACK\_TIMEOUT](aclError.md)

 This return code will be deprecated in later versions. Use the [ACL\_ERROR\_RT\_REPORT\_TIMEOUT](aclError.md) return code instead.

- [ACL\_ERROR\_INVALID\_DEVICE](aclError.md)

 This return code will be deprecated in later versions. Use the [ACL\_ERROR\_RT\_INVALID\_DEVICEID](aclError.md) return code instead.

- [ACL\_ERROR\_GROUP\_NOT\_SET](aclError.md)

 This return code will be deprecated in later versions. Use the [ACL\_ERROR\_RT\_GROUP\_NOT\_SET](aclError.md) return code instead.

- [ACL\_ERROR\_GROUP\_NOT\_CREATE](aclError.md)

 This return code will be deprecated in later versions. Use the [ACL\_ERROR\_RT\_GROUP\_NOT\_CREATE](aclError.md) return code instead.
