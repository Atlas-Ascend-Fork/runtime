| Data Format| Description|
| --- | --- |
| ACL_RT_DEV_RES_CUBE_CORE = 0 | AI Core or Cube Core|
| ACL_RT_DEV_RES_VECTOR_CORE=1 | Vector Core |

For the definition and detailed description of Cores, see [aclrtDevAttr](aclrtDevAttr.md).
