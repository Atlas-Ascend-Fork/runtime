# aclCANNPackageName

| Data Format| Description|
| --- | --- |
| ACL_PKG_NAME_CANN | Queries the CANN version number.|
| ACL_PKG_NAME_RUNTIME | Queries the Runtime version number in CANN.|
| ACL_PKG_NAME_COMPILER | Queries the Compiler version number in CANN.|
| ACL_PKG_NAME_HCCL | Queries the HCCL version number in CANN.|
| ACL_PKG_NAME_TOOLKIT | Queries the Toolkit version number in CANN.|
| ACL_PKG_NAME_OPP | Queries the Opp version number in CANN.|
| ACL_PKG_NAME_OPP_KERNEL | Queries the kernels version number in CANN.|
| ACL_PKG_NAME_DRIVER | Queries the Driver version number.|
