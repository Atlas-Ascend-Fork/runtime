# aclCANNPackageVersion

| Name| Description|
| --- | --- |
| version | String, complete version number.|
| majorVersion | String, major version.|
| minorVersion | String, minor version.|
| releaseVersion | String, release version. If the number cannot be queried, `0` is used.|
| patchVersion | String, patch version. If the number cannot be queried, `0` is used.|
| reserved | String, reserved value. By default, this parameter is left blank.|
