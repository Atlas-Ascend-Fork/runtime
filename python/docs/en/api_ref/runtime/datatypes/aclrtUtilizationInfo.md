# aclrtUtilizationInfo

| Data Format| Description|
| --- | --- |
| cube_utilization | Int, Cube operator usage.|
| vector_utilization | Int, Vector operator usage.|
| aicpu_utilization | Int, AI CPU operator usage.|
| memory_utilization | Int, device memory usage.|
| utilization_extend | Int, reserved for extension. This field is not supported in the current version.|
