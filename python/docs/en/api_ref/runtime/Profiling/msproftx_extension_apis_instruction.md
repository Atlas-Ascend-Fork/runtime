# Overview

- **Requirements for API calls**: msproftx function APIs must be called between [acl.prof.start](function-start.md) and [acl.prof.stop](function-stop.md). The APIs used for pairing are [acl.prof.create\_stamp](function-create_stamp.md)/[acl.prof.destroy\_stamp](function-destroy_stamp.md), [acl.prof.push](function-push.md)/[acl.prof.pop](function-pop.md) and [acl.prof.range\_start](function-range_start.md)/[acl.prof.range\_stop](function-range_stop.md).
- **API call sequence**: [acl.prof.start](function-start.md) API (specify Device 0 and Device 1) --\> [acl.prof.create\_stamp](function-create_stamp.md) --\> [acl.prof.set\_stamp\_trace\_message](function-set_stamp_trace_message.md) --\> [acl.prof.mark](function-mark.md) --\> \([acl.prof.push](function-push.md) --\> [acl.prof.pop](function-pop.md) (or [acl.prof.range\_start](function-range_start.md) --\> [acl.prof.range\_stop](function-range_stop.md)\) --\> [acl.prof.destroy\_stamp](function-destroy_stamp.md) --\> [acl.prof.stop](function-stop.md) (consistent with the **aclprofConfig** data of [acl.prof.start](function-start.md)).
